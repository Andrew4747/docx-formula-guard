# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-08-02

### Added

- read-only scanning for DOCX, LaTeX, Markdown, and plain-text files;
- Unicode anomaly and private-use character checks;
- configurable Word-to-MathType LaTeX compatibility warnings;
- duplicate and missing equation-number checks;
- Markdown and JSON reports;
- command-line interface, tests, and GitHub Actions workflow.
